# 📚 TOCFL Master

Ứng dụng web toàn diện được thiết kế để hỗ trợ người dùng ôn tập và luyện thi chứng chỉ năng lực tiếng Trung (TOCFL) với hệ thống từ vựng phồn thể và giao diện hiện đại.

---

## 🌟 Tính năng chính
* **Học từ vựng thông minh:** Cung cấp danh sách từ vựng phong phú kèm theo Pinyin, chữ Hán phồn thể và các bài tập luyện tập.
* **Giao diện trực quan:** Thiết kế thân thiện, dễ sử dụng, tối ưu hóa trải nghiệm học tập cho người dùng.
* **Quản lý dữ liệu linh hoạt:** Hệ thống backend và frontend kết nối chặt chẽ để lưu trữ và xử lý tiến trình học tập.

---

## 🛠️ Công nghệ sử dụng (Tech Stack)

### **Frontend:**
* **Framework:** React / TypeScript (`frontend/src/App.tsx`)
* **Styling:** TailwindCSS
* **Build Tool:** Vite

### **Backend:**
* **Runtime:** Node.js / Express
* **Database & Xử lý:** Tích hợp các thư viện xử lý dữ liệu (Excel, JSON) phục vụ lưu trữ từ vựng.
